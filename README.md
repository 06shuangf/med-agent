# MedAgent — 医疗多智能体系统

对标医疗 AI Agent 算法岗位的完整能力演示:5 个智能体 + 医疗知识工程 + 医学工具链 + 推理算法对比 + 评测门禁。
零第三方依赖(纯 Python 标准库),架构复用并强化 FinResearchAgent 的"软审阅 + 硬门禁"双层防线。

> ⚠️ 教学演示项目:知识卡/工具数据为教学级简化内容,不用于真实临床。
> 生产替换点见各模块 docstring(LIS/合理用药系统/指南库/HIS)。

## 快速开始

```bash
export PIXDANCE_CHAT_KEY=sk-...     # 需网关有余额

python -m medagent.cli "空腹血糖 7.2,是糖尿病吗?" --trace          # 诊断推理 Agent(ReAct)
python -m medagent.cli "任务" --mode cot|self_refine|tot           # 切换推理算法
python -m medagent.cli --ask "静脉溶栓的时间窗是多少小时?"          # 文献指南 Agent(RAG)
python -m medagent.cli --record "患者男,54岁。主诉:..."            # 病历分析 Agent
python -m medagent.cli --consult --patient p001                    # 问诊 Agent(多轮+记忆)
python -m medagent.cli --eval                                       # 14 用例评测集+门禁
python -m medagent.cli --bench                                      # CoT/ReAct/Self-Refine/ToT 对比
```

## 五个智能体

1. **诊断推理 Agent**(旗舰):ReAct 循环调用医学工具;急症预检(命中红旗征系统层强制置顶就医指令);
   Self-Refine 模式下先自我审查(证据不足/过度解读/漏致命病因/违规表述)再修订;
   独立 Reviewer 按证据性/合规/结构/完整性四维审阅,不通过带意见重规划
2. **文献指南 Agent**:RAG 问答,三道反幻觉闸门——检索信号门控(得分过低直接拒答不调 LLM)、
   提示词强制 [MG-id] 引用、引用后校验过滤伪造引用
3. **病历分析 Agent**:结构化抽取(主诉/现病史/既往史/过敏史/用药)+ 确定性完整度校验(必备字段粗检)
   + 一致性检查 + 时间线
4. **问诊 Agent**:多轮对话,槽位抽取(主诉/持续时间/过敏史等)+ 短记忆窗口 + 患者档案长记忆
   (文件持久化跨会话)+ 急症中断机制(命中红旗立即停止采集优先就医指令)
5. **协调合规 Agent**:规则路由任务到子 Agent → 并行执行 → 证据强度仲裁
   (有指南引用 > 无引用;检验数据 > 纯症状)→ 聚合 → 医疗合规硬门禁终审

## 医学数据库(SQLite 单文件,零依赖)

`runtime/database.py` — `workspace/medagent.db`,对齐 JD#3「医疗向量数据库」与 JD#5「医疗知识库对接」:

| 表族 | 表 | 用途 |
|---|---|---|
| 知识向量库 | `kb_cards` / `kb_inverted` / `kb_vectors` / `kb_doc_meta` | 32 张知识卡的 TF-IDF 稀疏向量(3308 维非零项)+ 倒排索引(1084 token);向量余弦在库内 JOIN 计算,不加载全库;接口对齐 Milvus/Chroma,生产可平移 |
| 患者库 | `patients` / `consultations` / `consult_messages` / `medical_records` / `medication_log` | 问诊长记忆的结构化存储:会话消息级落盘可回放,`patient_history()` 一次查出历史问诊+病历+用药 |
| 轨迹库 | `agent_traces` | Agent 执行轨迹入库;`badcase_report()` SQL 直查非 passed 轨迹,`usage_summary()` 汇总 token/耗时/通过率 |

**文献 Agent 双引擎检索**:内存混合检索(实体加权 BM25)+ DB 向量余弦,
RRF(k=60)融合排名;信号门控升级为三重判定——双引擎首位共识 × 内容锚点校验
(命中卡正文须含问题的内容词,防零散词撞高频医学词)+ 实体覆盖,任一不达标直接拒答不调 LLM。

**问诊 Agent 长记忆双通道**:SQLite 患者库优先(会话/消息/档案/用药全结构化),
DB 故障自动降级文件记忆,不阻塞问诊。

```bash
python -m medagent.cli --badcase   # 轨迹库 badcase 报表 + 用量汇总
```
